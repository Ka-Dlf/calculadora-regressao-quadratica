# Calculadora de Regressão Quadrática

## Sobre
A Calculadora de Regressão Quadrática é um projeto prático desenvolvido inteiramente com HTML, CSS e JavaScript. A aplicação tem como objetivo realizar cálculos estatísticos complexos, permitindo que o utilizador insira conjuntos de valores de **X** e **Y** para calcular a equação da parábola de melhor ajuste (y = cx + bx + ax²) utilizando o método dos mínimos quadrados. Projeto criado para a atividade avaliativa da matéria de estatística.
